iPhone / iPad 订阅

1在首页点「订阅光遇日历」，系统会自动唤起日历 App。
2弹出日历订阅确认页后，点右上角「添加」。
3打开系统「日历」App，底部点「日历」，找到刚订阅的日历。
重要：苹果会默认关掉订阅日历的提醒。
日历列表里，点这个订阅右边蓝色的 ⓘ，把「事件提醒」或「提醒」开关打开。关着的话，日程能显示但不会弹通知。

安卓手机订阅

安卓没有统一的"一键订阅"，需要手动把链接粘进日历 App。大部分品牌都支持。

1在首页点「订阅光遇日历」，链接会自动复制到剪贴板。
2打开手机自带的「日历」App。
3找「添加日历」或「订阅日历」入口。不同品牌位置不同：

华为：日历 → 右下角"≡" → 要显示的日历 → 添加账户 → 选择 CalDAV
小米：日历 → 设置 → 日历账号 → 添加订阅日历
OPPO/vivo：日历 → 设置 → 订阅日历 → 粘贴链接
三星：日历 → 三条线菜单 → 管理日历 → 添加日历 → URL

4把刚才复制的链接粘贴进去，确认添加。

如果你的日历 App 不支持订阅链接，可以装一个免费的 ICSx5（F-Droid）或用 Google 日历网页版添加。

关于这个日历

数据来源：网易大神官方动态和 BWiki 光遇。

每 6 小时自动同步一次官方公告。红石和黑石按游戏内固定规律计算，公告事件由后台审核后才会进日历。

这是一个个人兴趣小工具，不是官方服务。游戏更新了我会尽快跟，但偶尔可能慢一拍，以游戏内实际为准。
